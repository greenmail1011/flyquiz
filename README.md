# 飛答 FlyQuiz — 課堂即時互動系統

像 Kahoot 一樣的講師、學員搶答系統。學生用手機或平板掃 QR code 就能加入，不需要帳號；講師可以用手機遙控，也能把互動畫面放進 PowerPoint。

## 先試玩（不用任何設定）

用 Chrome 或 Edge 打開 `index.html`，點「我是講師」，再按範例題組的「▶ 開始活動」。另外開幾個新分頁，網址最後改成 `#/join/房間PIN`，就能扮演學生作答。

> 試玩模式只能在**同一台電腦的分頁之間**互動。要讓學生用自己的手機加入，請完成下面的「正式上線」。

---

## 正式上線（約 15 分鐘，免費）

### 1. 建立 Firebase 專案
1. 到 <https://console.firebase.google.com>，用 Google 帳號登入，按「新增專案」（Google Analytics 可以關閉）。
2. 左側「建構 → Authentication」→「開始使用」→「登入方式」分頁 → 選 **匿名** → 啟用 → 儲存。
3. 左側「建構 → Realtime Database」→「建立資料庫」→ 位置選 **新加坡 (asia-southeast1)** →「以鎖定模式啟動」。
4. 在 Realtime Database 的「規則」分頁，把裡面的內容**全部換成** `database.rules.json` 的內容，按「發布」。

### 2. 填入設定
1. 左上齒輪「專案設定」→「一般」→ 最下面「你的應用程式」→ 按網頁圖示 `</>` → 取個名字 → 註冊（不用勾 Hosting）。
2. 畫面會出現一段 `firebaseConfig = { ... }`。打開 `config.js`，把 `null` 換成大括號 `{ ... }` 那一段。
3. 確認裡面有 `databaseURL`。沒有的話，到 Realtime Database 頁面最上方複製網址，自己加一行：`databaseURL: "https://....firebasedatabase.app",`

### 3. 放上網路（擇一）
**A. 最簡單：Netlify Drop（拖拉即可）**
1. 打開 <https://app.netlify.com/drop>（免費註冊）。
2. 把整個 `flyquiz` 資料夾拖進去，幾秒後會得到一個網址，例如 `https://xxxx.netlify.app`。
3. 之後修改了檔案，到該網站的 Deploys 頁面再拖一次資料夾就會更新。

**B. Firebase Hosting（需要安裝 Node.js）**
```
npm install -g firebase-tools
firebase login
firebase init hosting   （選剛剛的專案；public 目錄填 . ；不要覆蓋 index.html）
firebase deploy
```
網址會是 `https://你的專案.web.app`。

完成後，用手機打開這個網址，就能看到「輸入 PIN」的畫面。

## 上課怎麼用

| 誰 | 做什麼 |
|---|---|
| 講師（電腦） | 打開網址 →「我是講師」→ 選題組 →「▶ 開始活動」，畫面投影到大螢幕 |
| 學生（手機／平板） | 掃大螢幕上的 QR code，或打開網址輸入 6 位數 PIN，取暱稱加入 |
| 講師（手機） | 按主持畫面右上角「📱 遙控」掃描，就能在教室任何位置切換題目、延長 10 秒、偷看正確答案 |

- **鍵盤**：空白鍵或 → 鍵是「下一步」。
- **移出學生**：在等待畫面點學生名字，就能把亂取名的學生移出。
- **遙控 QR code 只能用一次**：連上後會自動換新，學生看到投影也無法搶走遙控權。
- **斷線不怕**：學生重新整理會回到原本的狀態；講師不小心關掉分頁，回到題庫按「回到主持畫面」就能繼續。

### 分組模式
- 在等待畫面下方的「分組」選 2～6 組；下次開房會記住這個設定。
- **學生自選**：加入後手機會出現組別按鈕，開始前可以按「換組」。
- **講師拖曳**：在大螢幕上把學生名字拖到另一組（滑鼠、觸控螢幕都可以）；點一下名字仍是「移出」。
- **隨機分組**：一鍵把所有人平均分到各組，再用拖曳微調。
- **分組設定**：可改**每組上限**（預設 15 人）和組名。滿了的組，學生手機上會變灰、顯示「已滿」；講師拖曳也會被擋下（要放更多人就先調高上限）；隨機分組會依上限分配，分不下的人留在「還沒選組」。
- 計分：**組別分數＝組員平均分**，人數不同也公平。排行榜和頒獎台改以組別排名，並列出個人前三名（MVP）。

### 題型
| 題型 | 計分 | 說明 |
|---|---|---|
| 選擇題 | ✓ | 2–6 個選項，可設多個正確答案（學生選中任一個就算對） |
| 是非題 | ✓ | 對／錯 |
| 填答題 | ✓ | 學生輸入文字；比對時忽略大小寫、空白、全半形與標點。可設多種正確寫法（如「4」和「四」） |
| 排序題 | ✓ | 輸入正確順序，學生看到的會自動打亂；全部排對才得分 |
| 投票 | ✗ | 顯示每個選項的票數 |
| 文字雲 | ✗ | 大螢幕即時長出文字雲 |

題目中的程式碼用 ```` ``` ```` 包起來，會以程式碼格式顯示（適合 APCS 觀念題）。

**計分方式**：答對基本分最高 1000 分，越快回答分數越高（最慢仍有 500 分）。雙倍分數題乘以 2。連續答對每題再加 100 分，最多加 500 分。

### 用 Excel 匯入題目
欄位順序：**題型、題目、選項A、選項B、選項C、選項D、答案、秒數**（請參考 `題目範本.csv`）。

- 選擇題的答案寫 `A`、`B`…；多個正確答案寫 `B,D`。
- 是非題寫 `對` 或 `錯`（也接受 O／X）。
- 填答題寫可接受的答案，多個用 `|` 分開，例如 `12|十二`。
- 排序題把選項**依正確順序**填在選項 A～D，答案欄留白。
- 投票、文字雲的答案欄留白。

可以直接從 Excel 複製表格，貼到「匯入題目」視窗；也可以選擇 .xlsx 或 .csv 檔。Windows Excel 存出的 Big5 編碼 CSV 也讀得懂。

## 放進 PowerPoint

在題庫或編輯畫面按 **「放進簡報」**，會得到這個題組的**固定網址**。之後修改題目會自動同步，簡報不用重做。

### 方法一：下載現成投影片（所有版本都適用）
1. 按「下載投影片 (.pptx)」。
2. 打開下載的檔案，把那張投影片複製貼到你的簡報裡。
3. 放映時點 **▶ 開始互動**，會用瀏覽器開啟互動畫面（再按右上角 ⛶ 全螢幕）。結束後按 **Alt+Tab** 回到簡報。

### 方法二：直接嵌入投影片（PowerPoint 2021、2024、Microsoft 365）
1. 「插入 → 增益集 → 取得增益集」，搜尋並加入 **Web Viewer**（只需要做一次）。
2. 在要互動的投影片按「插入 → 我的增益集 → Web Viewer」。
3. 貼上網址（Web Viewer 會自動補上 `https://`，重複的話請刪掉一個）→ Preview → 把框拉滿整張投影片。
4. 放映翻到這頁按「開啟房間」，翻到下一頁就繼續上課。翻回來時會自動回到同一場活動。

**小提醒**
- 建議同一張投影片同時放「方法一」的按鈕。遇到舊版或沒更新的 PowerPoint 無法嵌入時，畫面會提示改點按鈕，不會一片空白。
- 嵌入模式下，請用**手機遙控**操作：放映中按鍵盤會先被 PowerPoint 接走。
- Web Viewer 只接受 https 網址，所以必須先完成「正式上線」。試玩模式的網址無法嵌入。

## 題庫雲端同步（不用登入）

- 所有電腦、手機打開「我是講師」，看到的都是**同一份雲端題庫**（右上角顯示「☁ 雲端題庫・所有裝置同步」）。
- 每台裝置第一次打開時，會**自動把那台裝置原有的題組複製一份上雲端**；本機原本的題組不會被刪除。
- 在任何裝置新增、修改、刪除題組，其他裝置重新整理就會看到。
- 「放進簡報」的網址在任何裝置都一樣，改題目後簡報不用重做。
- 注意：因為不用登入，知道網址的人點「我是講師」也看得到題庫（含答案）。需要時可以再加講師密碼。

## 常見問題

**題組存在哪裡？** 存在雲端（Firebase），每台裝置的瀏覽器裡也各留一份當初的副本。也可以按「備份」下載 .json 檔保存。

**免費額度夠嗎？** Firebase 免費方案可以同時連線 100 人，每月 10 GB 流量。一個班 30 人每天上課綽綽有餘。

**學生會不會先看到答案？** 不會。正確答案只存在講師的電腦裡，公布後才送出。資料庫規則也限制學生只能寫入自己的暱稱和作答，而且每題只能交一次、超過時間就無法送出。

## 檔案說明
| 檔案 | 用途 |
|---|---|
| `index.html` | 整個系統（講師、學生、遙控、投影片頁面都在這一個檔案） |
| `config.js` | Firebase 設定（你只需要改這個檔） |
| `database.rules.json` | 資料庫安全規則，貼到 Firebase 主控台 |
| `lib/` | QR code、Excel 讀取、PowerPoint 產生的函式庫（已內建，不需要網路下載） |
| `題目範本.csv` | 匯入題目的範例 |
| `firebase.json` | 使用 Firebase Hosting 部署時才需要 |
